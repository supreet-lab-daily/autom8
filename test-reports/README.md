# Salesforce Test Reports

This directory contains automated test execution reports organized by year and month.

## Latest Reports

- [2026-01-29](./2026/01/2026-01-29/report.md)

## Directory Structure

Reports are organized by:
- `YYYY/MM/YYYY-MM-DD/` - Daily test reports
- Each report includes: `report.json`, `report.md`, `report.html`

## Viewing Reports

- **Markdown:** View `report.md` directly in GitHub
- **JSON:** Download `report.json` for programmatic access
- **HTML:** Download and open `report.html` in a browser

---

_Reports are automatically generated by the Salesforce Test Runner workflow._
